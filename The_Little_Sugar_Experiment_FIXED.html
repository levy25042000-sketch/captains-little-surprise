EXPERIMENT 01 / 05RECURSIVE STRUCTURES

The recurrence engine

A sequence is generated by a rule. Recover the next state.

1, 4, 15, 64, 325, 1956, ?

For n = 2, 3, 4, ... each term is generated by aₙ = n(aₙ₋₁ + 1), with a₁ = 1. What is the seventh term?

The transition from a₆ to a₇ uses n = 7.
Apply aₙ = n(aₙ₋₁ + 1), starting from a₁ = 1.

EXPERIMENT 03 / 05BAYESIAN INFERENCE

The base-rate trap

A rare condition affects 1% of a population. A test has 95% sensitivity and a 5% false-positive rate. Assume these values are exact.

P(C)=0.01 · P(+|C)=0.95 · P(+|¬C)=0.05

A randomly selected person tests positive. What is P(C | +)? Give your answer as a percentage to one decimal place.

Use Bayes' theorem. The denominator is the total probability of a positive result.
Compute (0.95 × 0.01) / [(0.95 × 0.01) + (0.05 × 0.99)].

EXPERIMENT 04 / 05RSA · MODULAR ARITHMETIC

Public key, private thought

A toy RSA system uses p = 5, q = 11 and public exponent e = 3. The ciphertext is c = 17. Use the standard RSA decryption procedure.

n = pq = 55   ·   φ(n) = 40

Find the plaintext m, where m ≡ cᵈ (mod n) and d is the modular inverse of e modulo φ(n). Enter the integer m.

First solve 3d ≡ 1 (mod 40) using the extended Euclidean algorithm.
d = 27. Now calculate 17²⁷ mod 55 using repeated squaring.
